# 智慧叫號排隊系統 (Smart Queue Calling System)

專為診所、餐飲手搖、櫃檯服務、活動現場設計的現代化叫號排隊系統。  
零伺服器依賴、純前端設計，可直接部署在 **GitHub Pages** 免費使用！

---

## 🖥️ 顧客端與管理端獨立分離架構

本系統採用**雙頁面分離架構**，透過瀏覽器 `BroadcastChannel` 與 `LocalStorage` 達到**即時毫秒級跨視窗雙向同步**：

| 端點 | 網址路徑 | 適用設備 | 核心職責 |
| :--- | :--- | :--- | :--- |
| **現場顧客端 (大螢幕/取號機)** | [`index.html`](file:///Users/alicejih/Documents/cli/queue-calling-system/index.html) 或 `customer.html` | 外接電視螢幕、等候區平板、取號立牌 | 超大數位 LED 叫號看板、真人中文語音與叮咚聲廣播、顧客自助「按此取號」、純公開等候進度看板（無危險操作，防顧客誤觸） |
| **櫃檯管理端 (店員操作後台)** | [`admin.html`](file:///Users/alicejih/Documents/cli/queue-calling-system/admin.html) | 店員電腦、筆電、櫃檯手機/平板 | 選擇櫃檯、叫下一號/上一號/重叫、櫃檯代客發號、「**點擊卡片代表這號好了**」服務完成歸檔、誤按復原、今日歸零重置 |

### ⚡ 跨視窗即時連動流程
1. **店員在管理端點擊「叫下一號」** ➔ 顧客端大螢幕立刻同步跳號、號碼發光閃爍、響起清脆叮咚聲並真人語音廣播（「請 005 號至 1 號櫃檯辦理」）。
2. **顧客在現場螢幕點擊「按此取號」** ➔ 櫃檯管理端等候清單與人數即刻同步增加。
3. **店員點擊卡片標記「這號好了」** ➔ 顧客端進度看板即時將該號移出，保持最新等候狀態。

## 🌟 核心功能特色

1. **🎫 自助取號與櫃檯發號**
   - 顧客點擊「按此取號」自動發號（001、002...），並跳出排隊號碼牌小卡，顯示前方等候人數。
   - 櫃檯管理端支援「櫃檯代客發號」，方便店員協助長輩或現場貴賓抽號。

2. **📢 超大數位叫號看板**
   - 媲美銀行診所等級的發光 LED 叫號看板，具備跳號閃爍動畫。
   - **真人中文語音廣播**（Web Speech API）＋ **經典「叮咚～」兩聲提示音**（原生 Web Audio API 合成，免載外部音檔，離線也能響）。
   - 支援切換櫃檯（例如：1 號櫃檯、2 號櫃檯、快速取餐口、VIP 專櫃）。

3. **✅ 列表按下去代表這一號好了（核心特色）**
   - 清楚直觀的等候卡片。
   - **店員只要點擊任意一張等候號碼卡片，即代表「這號好了 / 服務完成」**！
   - 點擊後平滑移入「已完成清單」，並附帶等候耗時記錄。
   - 若完成的剛好是當前叫號號碼，系統會自動順延下一位。
   - 提供「誤按復原」功能，防範手滑。

4. **💾 本地持久化與離線可用**
   - 使用瀏覽器 `LocalStorage`，重新整理網頁、關閉瀏覽器資料不遺失。
   - 支援全螢幕展示大看板模式。
